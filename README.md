🛍️ Online Shop

📌 About the Project

Online Shop is a simple and responsive online shopping website created as a team project. The website allows users to explore products, view available services, and navigate between different pages.

✨ Features

- Responsive design
- Home page
- Login page
- Register page
- Forgot Password page
- Services page
- Shopping page
- Contact page
- Product categories
- Product cards with images and prices
- Clean and modern design

🛠️ Technologies Used

- HTML5
- CSS3
- Tailwind CSS
- Git
- GitHub

📁 Project Structure

- Home – Main page of the online shop
- Login – User login page
- Register – Account registration page
- Forgot Password – Password recovery page
- Services – Shows the services provided by the shop
- Shopping – Displays products and categories
- Contact – Contact information

🎨 Design

The website uses a clean and modern color combination of:

- Blue
- Light Blue
- White
- Gray

The pages are designed to be responsive on different screen sizes.

👥 Team Project

This project was developed as a team using Git and GitHub. Each team member worked on different parts of the website, including pages, styling, and content.

🚀 How to Run

1. Download or clone the repository.
2. Open the project in VS Code.
3. Open the HTML files in a browser.
4. For a better experience, use the Live Server extension in VS Code.
